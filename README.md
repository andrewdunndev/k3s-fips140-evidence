# k3s FIPS 140-3 evidence

Test evidence for the k3s FIPS 140-3 proposal, https://github.com/k3s-io/k3s/issues/14984. It is logs and commands, not software.

- One directory per filing: `adr/` holds the evidence for the ADR.
- Each filing links to a tag of this repo (`adr-1` for the ADR), so the text a filing cites does not change.
- Each file holds one claim, the build, the commands and the log lines that show the result.
